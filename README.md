# GhostDesk Web

Веб-приложение GhostDesk переносит интерфейс landing page в рабочий кабинет с авторизацией, хранением данных и личным профилем пользователя.

## Технологический стек
- **Next.js 14 + React 18** — рендеринг через App Router, серверные компоненты и маршруты API.
- **TypeScript** — строгая типизация компонентов и серверных обработчиков.
- **Tailwind CSS** — поддерживает фирменный градиентный стиль лендинга.
- **Prisma ORM + SQLite** — хранение пользователей и сессий, миграции базы данных.
- **Zod & bcryptjs** — валидация форм и безопасное хеширование паролей.

## Ключевые директории и файлы
- `web/app/(auth)/` — страницы логина и регистрации, оформленные в стиле лендинга.
- `web/app/(dashboard)/` — приватные разделы приложения (дашборд, настройки и т.д.) под App Shell.
- `web/app/api/auth/` — API-обработчики входа, регистрации и выхода.
- `web/app/api/settings/profile/route.ts` — обновление профиля пользователя.
- `web/components/layout/app-shell.tsx` — основной каркас интерфейса с сайдбаром и шапкой.
- `web/components/auth/` — формы и кнопки, связанные с авторизацией.
- `web/components/settings/profile-form.tsx` — форма редактирования профиля.
- `web/lib/auth.ts` — утилиты для работы с сессиями, паролями и текущим пользователем.
- `web/prisma/schema.prisma` — схема базы данных (пользователь и сессии).

## Настройка окружения
1. Убедитесь, что установлен Node.js 18 или новее и npm 9+.
2. Склонируйте репозиторий и перейдите в папку `web/`:
   ```bash
   git clone <repo-url>
   cd ghostdesk_web/web
   ```
3. Создайте файл окружения и отредактируйте при необходимости `DATABASE_URL` (по умолчанию SQLite-файл `prisma/dev.db`):
   ```bash
   cp .env.example .env
   ```
4. Установите зависимости:
   ```bash
   npm install
   ```
5. Примените миграции базы данных (создаст файл `prisma/dev.db`):
   ```bash
   npx prisma migrate dev --name init
   ```

### Локальный запуск (macOS)
1. Выполните шаги из раздела выше.
2. Запустите dev-сервер Next.js:
   ```bash
   npm run dev
   ```
3. Откройте `http://localhost:3000` — доступны страницы регистрации/входа, дашборд и настройки профиля.

### Развёртывание на сервере Ubuntu
1. Установите Node.js 18 LTS (например, через `curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -` и `sudo apt install -y nodejs`).
2. Склонируйте репозиторий и перейдите в `ghostdesk_web/web`.
3. Скопируйте `.env.example` в `.env` и при необходимости задайте абсолютный путь для `DATABASE_URL`, чтобы SQLite-файл лежал в постоянном каталоге.
4. Установите зависимости:
   ```bash
   npm ci
   ```
5. Примените миграции без генерации новых (боевые окружения):
   ```bash
   npx prisma migrate deploy
   ```
6. Соберите и запустите приложение:
   ```bash
   npm run build
   npm run start -- --hostname 0.0.0.0 --port 3000
   ```
   Рекомендуется обернуть команду в `pm2`, `systemd` или Docker для фонового запуска.
7. Настройте nginx или другой обратный прокси для HTTPS и домена (например, пробрасывая трафик на `localhost:3000`).

После запуска используйте страницу `/auth/register` для создания первого пользователя и доступа к кабинету.
