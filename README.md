# GhostDesk Web

Минимальная веб-версия GhostDesk, включающая только страницы регистрации и авторизации с серверными маршрутами и сессиями.

## Технологический стек
- **Next.js 14 + React 18** — рендеринг через App Router и встроенные API-маршруты.
- **TypeScript** — статическая типизация клиентских и серверных модулей.
- **Tailwind CSS** — оформление в стилистике лендинга.
- **Prisma ORM + SQLite** — хранение пользователей и сессий.
- **Zod & bcryptjs** — валидация данных и безопасное хеширование паролей.

## Структура проекта
- `web/app/(auth)/` — страницы входа и регистрации с общим градиентным макетом.
- `web/app/api/auth/` — обработчики POST-запросов для логина, регистрации и выхода.
- `web/lib/` — Prisma-клиент и вспомогательные функции авторизации.
- `web/components/auth/` — клиентские формы и кнопка выхода.
- `web/prisma/` — схема базы данных и миграция `init`.

## Подготовка окружения
1. Установите Node.js 18+ и npm 9+.
2. Клонируйте репозиторий и перейдите в директорию `web/`:
   ```bash
   git clone <repo-url>
   cd ghostdesk_web/web
   ```
3. Скопируйте пример переменных окружения и при необходимости измените `DATABASE_URL` (по умолчанию `file:./prisma/dev.db`):
   ```bash
   cp .env.example .env
   ```
4. Установите зависимости:
   ```bash
   npm install
   ```
5. Примените миграцию и сгенерируйте Prisma Client:
   ```bash
   npx prisma migrate dev --name init
   ```

## Локальный запуск на macOS
1. Выполните подготовку окружения из раздела выше.
2. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
3. Откройте `http://localhost:3000/auth/register` для создания пользователя или `http://localhost:3000/auth/login` для входа.

## Развёртывание на сервере Ubuntu
1. Установите Node.js 18 LTS (например, через Nodesource или nvm).
2. Склонируйте репозиторий и перейдите в `ghostdesk_web/web`.
3. Создайте `.env`, укажите постоянный путь для SQLite при необходимости.
4. Установите зависимости без изменения lock-файла:
   ```bash
   npm ci
   ```
5. Примените миграции в production-режиме:
   ```bash
   npx prisma migrate deploy
   ```
6. Соберите и запустите приложение:
   ```bash
   npm run build
   npm run start -- --hostname 0.0.0.0 --port 3000
   ```
7. Настройте процесс-менеджер (`pm2`, `systemd`) и обратный прокси для HTTPS при необходимости.

Создайте первого пользователя на `/auth/register`, затем используйте `/auth/login` для авторизации. Кнопка «Выйти» доступна на обеих страницах после входа.
